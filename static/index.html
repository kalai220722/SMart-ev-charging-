SafeStation Reinforcement Learning MDP Formulation

The Safe Station Environment is a discrete-time Markov Decision Process (MDP) designed for Meta's PyTorch OpenEnv Hackathon 2026. The agent manages an intelligent dual-source commercial charging depot balancing real-time wholesale grid electricity prices, electrochemical battery degradation limits, and EV driver satisfaction.

1. State & Action Formulations

State Vector (Observation):
  • hour: [0 - 23] (time of day)
  • grid_price: ₹4.0 (off-peak), ₹8.0 (normal), ₹15.0 (peak)
  • station_battery_level: [0 - 1000 kWh] BESS charge
  • car_present: [0 or 1] EV bay status
  • car_battery_need: [0 - 1000 kWh] energy required
Action Space (Discrete {0, 1, 2, 3}):
  • Action 0 (Grid): Draw 20 kW from Grid to Car
  • Action 1 (BESS): Discharge 20 kW from BESS to Car
  • Action 2 (Top-up): Draw ≤ 30 kW from Grid to BESS
  • Action 3 (Hybrid): Dual 20 kW Grid + 20 kW BESS (40 kW total)

2. Reward & Constraint System

Reward Incentives:
  • +200.0: Complete EV charge fulfillment
  • +50.0: Peak-Shaving bonus (BESS used when grid > ₹10)
  • +(Energy × 6.0): Strategic off-peak storage bonus
Operational Penalties:
  • -(Energy × Price): Direct grid operational expense
  • -5.0 / step: Car wait penalty while incomplete
  • -500.0: CRITICAL FAILURE if BESS reaches 0 floor
